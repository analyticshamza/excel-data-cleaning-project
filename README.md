# 🧹 Employee Data Cleaning Project (Excel)

## 📄 Overview
This project demonstrates basic data cleaning and preparation techniques using Microsoft Excel. The dataset contains employee information including names, job roles, and salaries. Key operations like sorting and filtering were used to extract insights and prepare the data for analysis.

## 🎯 Objectives
- Sort employees by salary (descending)
- Sort employees alphabetically by name
- Filter employees by job role ("Developer")
- Filter employees by salary range ($50,000 – $55,000)
- Identify key employee insights

## 🧠 Key Insights
- **Highest Salary**: John Doe – $60,000  
- **Lowest Salary**: Michael Brown – $48,000  
- **First Alphabetically**: Emily Davis  
- **Number of Developers**: 1 (Jane Smith)  
- **Employees Earning $50K–$55K**: 6

## 📊 Excel Features Used
- Sort (A to Z)
- Filter (by Text & Number)
- Number Filters → Between
- Sheet organization for tasks

## 📂 Project Files
- `Employee_Data_Cleaning_Report.xlsx` – contains all task sheets:
  - Sheet1: Employee_Master_Data  
  - Sheet2: Sorted_By_Salary  
  - Sheet3: Sorted_By_Name  
  - Sheet4: Filter by Job Role  
  - Sheet5: Salary_50k_to_55k
- `Employee_Data_Cleaning_Report.pdf` – final summary report
